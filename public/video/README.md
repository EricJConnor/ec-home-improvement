Pexels licence: free to use, no credit required. Every mp4 is H.264 High, yuv420p, +faststart
(anything else is blank on an iPhone). Each loop's last second is crossfaded into its first so
there is no jump. The CLAUDE.md hero notes explain how to get files out of Pexels from here.
